🖥️ ¿Qué es una computadora?

⬆ Subir Siguiente →

Una computadora (también llamada ordenador o PC) es una máquina electrónica que recibe datos, los procesa y los convierte en información útil. Piensa en ella como un asistente que puede hacer cálculos millones de veces más rápido que una persona, almacenar enormes cantidades de información y conectarte con el mundo.

En la Jurisdicción Sanitaria N°V, la computadora nos sirve para:

  • Redactar documentos: Oficios, memorándums, circulares, informes.
  • Capturar datos: Estadísticas de salud, censos, reportes, SIS.
  • Comunicarnos: Correo electrónico, reuniones virtuales.
  • Almacenar información: Expedientes, bases de datos.
  • Imprimir y escanear: Documentos oficiales, formatos.

Las dos partes fundamentales de toda computadora

🔧 Hardware (el cuerpo)

Partes físicas que puedes tocar: monitor, teclado, mouse, torre, cables, impresora.

💿 Software (la mente)

Programas que le dicen al hardware qué hacer: Windows, Word, Excel, Chrome, antivirus.

Ejercicio Práctico

Identifica las partes de tu computadora:

  1. Señala con tu mano el monitor donde estás leyendo esto.
  2. Toca el teclado y el mouse que tienes enfrente.
  3. Di en voz alta: "Esto es HARDWARE porque lo puedo tocar".
  4. Ahora di: "Windows y Word son SOFTWARE porque son programas".

📱 Tipos de computadoras

← Anterior Siguiente →

En la Jurisdicción usamos diferentes tipos. Conocer sus diferencias te ayudará a elegir la adecuada.

🖥️ De Escritorio

Torre + monitor + teclado + mouse. La más potente y fácil de reparar. Ideal para oficinas.

💻 Laptop

Todo en uno. Se lleva a reuniones, brigadas y trabajo de campo. Tiene batería para usar sin corriente.

📱 Tablet

Pantalla táctil. Ideal para censos, encuestas de salud y trabajo de campo.

Ejercicio Práctico

¿Qué tipo de computadora tienes? Observa tu equipo y responde:

  1. ¿Tiene una torre separada del monitor? → Es de escritorio.
  2. ¿Es todo en uno, delgada y con batería? → Es una laptop.
  3. ¿Es solo una pantalla táctil? → Es una tablet.
✓ Identificado

🔧 Partes externas

← Anterior Siguiente →

Estas son las piezas que ves todos los días en tu escritorio.

🖥️ Monitor

La pantalla donde ves oficios, expedientes y sistemas de salud.

🖱️ Mouse

Controla el cursor. Botón izquierdo (seleccionar), derecho (menú), rueda (scroll).

⌨️ Teclado

Para escribir. Tiene letras, números, teclas de función (F1-F12) y especiales (Ctrl, Alt).

🔊 Bocinas

Para escuchar videollamadas, capacitaciones y sonidos del sistema.

🎧 Audífonos

Para reuniones virtuales sin molestar a compañeros. Algunos tienen micrófono.

🖨️ Impresora

Imprime oficios, reportes y formatos. Algunas también escanean y copian.

🔌 Puertos USB

Para conectar mouse, teclado, memorias USB, discos externos, impresoras y más.

Ejercicio Práctico

Identifica 3 periféricos en tu escritorio:

  1. Mira a tu alrededor y encuentra el monitor (la pantalla).
  2. Busca el mouse (el aparato que mueves con la mano).
  3. Busca el teclado (donde escribes).
  4. ¿Tienes bocinas, audífonos o una impresora cerca? Esos también son periféricos.

🔬 Partes internas

← Anterior Siguiente →

Dentro de la torre o laptop están los componentes más importantes. Son como los órganos del cuerpo.

🧠 Procesador (CPU)

El cerebro. Hace todos los cálculos. Entre más rápido, más ágil es tu PC.

🧩 Memoria RAM

Memoria temporal. Guarda los programas abiertos. Más RAM = más programas sin que se trabe.

💾 Disco Duro

Guarda todo tus archivos de forma permanente: fotos, documentos, programas.

📋 Tarjeta Madre

La placa principal que conecta todos los componentes entre sí.

Ejercicio Práctico

Completa las frases:

  1. El ______ es el cerebro de la computadora. (Respuesta: procesador)
  2. La memoria ______ guarda los programas abiertos temporalmente. (Respuesta: RAM)
  3. El ______ ______ guarda todos tus archivos para siempre. (Respuesta: disco duro)

🪟 El Sistema Operativo (Windows)

⬆ Subir Siguiente →

El sistema operativo es el programa más importante de la computadora. Gestiona el hardware y permite que los demás programas funcionen. Es como el capitán del barco que organiza todo. En la Jurisdicción usamos Microsoft Windows.

Funciones principales:

  • Gestionar el hardware (procesador, memoria, disco).
  • Administrar archivos y carpetas.
  • Ejecutar programas (Word, Excel, Chrome).
  • Controlar la seguridad (contraseñas, firewall, Defender).
  • Manejar la red y la conexión a internet.

💡 ¿Sabías que...?

Presiona Windows + R, escribe winver y Enter para saber tu versión de Windows.

🪟 Ventanas de Aplicación

← Anterior Siguiente →

Cada programa que abres (Word, Excel, Chrome, una carpeta) se muestra dentro de un recuadro llamado ventana. Aprender a controlar las ventanas es fundamental para usar la computadora.

Partes de una ventana

📄 Documento - Word

Aquí va el contenido del programa

En la barra superior de cada ventana (llamada barra de título) hay tres botones en la esquina derecha:

➖

Minimizar

El botón con un guión ➖. Oculta la ventana y la manda a la barra de tareas. El programa sigue abierto, solo no se ve.

⬜

Maximizar / Restaurar

El botón del cuadrado. Maximizar agranda la ventana para que ocupe toda la pantalla. Restaurar la devuelve a su tamaño anterior.

✖

Cerrar

El botón de la X en rojo. Cierra el programa por completo. Si no has guardado, Windows te preguntará si quieres guardar.

Cómo mover una ventana

Coloca el cursor sobre la barra superior

La barra de título (donde está el nombre del programa).

Mantén presionado el botón izquierdo del mouse

Arrastra la ventana a la posición que quieras

Verás que la ventana se mueve con el mouse.

Suelta el botón

La ventana se queda en la nueva posición.

Pantalla dividida con dos ventanas (Split Screen)

Windows te permite dividir la pantalla para ver dos programas al mismo tiempo. Esto es muy útil cuando, por ejemplo, estás escribiendo un oficio en Word y consultando datos en Excel.

Abre los dos programas que quieras usar

Por ejemplo, Word y Excel, o Chrome y Word.

Arrastra una ventana al borde izquierdo

Haz clic en la barra superior, mantén presionado y arrastra hasta que el cursor toque el borde izquierdo.

Suelta el mouse

La ventana se ajusta automáticamente a la mitad izquierda.

Elige la segunda ventana

Windows te mostrará las otras ventanas. Haz clic en la que quieras.

Oficio
📊 Excel

Ejercicio Práctico: Abre y minimiza una ventana

  1. Haz clic en el ícono de Word o Chrome en tu escritorio.
  2. Identifica los tres botones: ➖ (minimizar), ⬜ (maximizar), ✖ (cerrar).
  3. Haz clic en ➖. La ventana desaparece pero el programa sigue abierto.
  4. Haz clic en el ícono en la barra de tareas para que vuelva.
  5. Haz clic en ⬜ para maximizar. Vuelve a hacer clic para restaurar.
✓ Lo practiqué

Ejercicio Práctico: Pantalla dividida

  1. Abre Word y también Chrome o Excel.
  2. Arrastra Word al borde izquierdo hasta ver un contorno y suelta.
  3. Arrastra la otra ventana al borde derecho.
  4. ¡Tienes dos programas visibles al mismo tiempo!
